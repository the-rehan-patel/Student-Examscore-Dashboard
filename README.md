# Student-s-Performance-Data-Analysis

Exam Score Dashboard (Power BI)
Interactive Power BI dashboard for analyzing student exam performance and the factors that influence scores.

Project summary
Built an interactive Power BI dashboard to explore student exam outcomes and related performance factors (study hours, attendance, parental involvement, socio-economic and school variables). The report enables quick filtering, comparison of students/groups, and visual identification of trends and outliers to support data-driven academic decisions.

Data schema
Dataset from kaggle.com

Table: StudentPerformanceFactors

Key visuals & features
(What the dashboard contains / what it’s designed to show)
Score distribution (histogram) and summary KPIs (average, median, top score)
Scatter plot: Hours_Studied vs Exam_Score (with trendline)
Boxplots / violin charts by School_Type or Gender
Heatmap or correlation matrix (to inspect relationships among Exam_Score and factors)
Slicers/filters for Gender, School_Type, Parental_Education_Level, Internet_Access, and date/term (if present)
Drill-through / individual student detail view (compare single student to class averages)
Trend lines for Previous_Scores → Exam_Score to assess improvement
Conditional formatting to highlight top/low performers and at-risk students
